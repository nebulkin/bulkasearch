# 🥐 BulkaSearch

Поиск красивых Telegram-юзернеймов: фильтр по длине/брендам, рейтинг, оценка в TON, ловушка, личный кабинет.

## Переменные окружения
`BOT_TOKEN` (@BotFather) · `API_ID`, `API_HASH` (my.telegram.org) · `TG_SESSION` (строка из `python gen_session.py`) ·
`DB_PATH` (по умолчанию `data.db`) · `TRAP_INTERVAL` (сек, по умолчанию 600) · `MAX_TRAPS` (10) · `OWNER_ID` (твой Telegram ID, нужен для смены ника)

## Render
Web Service → Build: `pip install -r requirements.txt` → Start: `python bot.py` → добавь env-переменные.
На free-плане сервис засыпает без входящих запросов: пингуй `/health` раз в 5 мин (UptimeRobot / cron-job.org).
База SQLite на free-плане стирается при каждом деплое — для постоянства подключи Render Disk (путь в `DB_PATH`).

## Userbot-режим
Сессия `TG_SESSION` — это твой аккаунт, поэтому ник можно ставить двумя способами:
- в любом чате напиши `.nick name` — сообщение превратится в результат;
- в боте: `/set name` или кнопка ✏️ под результатом (только `OWNER_ID`, с подтверждением).

## Интерфейс
`/start` открывает меню с кнопками: поиск (режим → длина), оценка, кабинет, помощь. Результат поиска и оценка приходят **картинкой-карточкой** (`card.py`, шрифт в `fonts/`), под ней кнопки ⭐ / 🪤 / ✏️ Поставить ник (userbot).
